# 🎬 AI 영상 스튜디오

Agnes AI 영상 생성 API를 **브라우저에서 직접 호출**하는 텍스트→영상 웹앱. 서버가 필요 없습니다.

## ✨ 기능

- **API 키 설정**: 본인의 Agnes AI API 키를 입력 → 이 브라우저(localStorage)에만 저장
- **영상 생성**: 프롬프트 입력 → 화면비율(16:9 / 9:16 / 1:1) → 길이(5초 / 10초) → 모델명 선택 → 생성
- **진행 상태**: 제출 → AI 생성 중(경과 시간·진행률) → 완료, 취소 버튼
- **결과**: 영상 미리보기 + MP4 다운로드
- **히스토리**: 최근 30개 기록 (다시 보기 / 다운로드 / 삭제)

## 🚀 사용법

1. https://metasongi.github.io/ai-video-studio/ 접속
2. ① API 키 설정에서 본인의 Agnes AI API 키를 저장
3. ② 프롬프트를 입력하고 "영상 생성" 클릭
4. ③ 생성이 끝나면(수 분 소요) 미리보기 + MP4 다운로드

## 🔑 API 키 안내

- 키는 이 브라우저에만 저장되며, 영상 생성 요청 시 `https://apihub.agnes-ai.com`으로 직접 전송됩니다.
- 키를 삭제하면 브라우저에서도 완전히 지워집니다.

## ⚠️ 제약 사항

- 영상 생성에는 수 분이 걸릴 수 있습니다 (15초 간격 폴링, 최대 15분).
- 무료 플랜은 레이트 리밋(429)이 있을 수 있습니다 — "무료 한도 초과" 메시지가 뜨면 잠시 후 재시도하세요.
- 히스토리의 영상 URL은 시간이 지나면 만료될 수 있습니다. 필요한 영상은 MP4로 다운로드해 보관하세요.
- 광고 차단 확장 프로그램이 API 호출을 막는 경우, 오류 메시지가 표시됩니다.

## 🛠 기술

- 단일 `index.html`, 외부 의존성 없음 (CDN 없음)
- `POST /v1/videos` 제출 → `GET /agnesapi?video_id=...` 폴링
- 인증: `Authorization: Bearer <API키>` 헤더
